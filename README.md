# 🌸 Florería Ámbar

Aplicación móvil desarrollada en **Flutter** para la gestión de una florería, enfocada en facilitar la compra de arreglos florales, la personalización de pedidos, la administración de productos y el seguimiento de entregas.

---

## 📱 Descripción

**Florería Ámbar** permite a los clientes consultar productos disponibles, realizar pedidos, personalizar arreglos florales y revisar el estado de sus solicitudes.

La aplicación también cuenta con funciones específicas para administradores y repartidores, permitiendo gestionar pedidos, productos, solicitudes personalizadas y entregas.

---

## ✨ Funcionalidades

### 👤 Cliente
- Registro e inicio de sesión
- Consulta de productos disponibles
- Visualización de categorías
- Carrito de compras
- Realización de pedidos
- Selección de fecha y hora de entrega
- Personalización de arreglos florales
- Consulta de pedidos realizados
- Consulta de arreglos personalizados aceptados
- Perfil de usuario
- Consulta de ubicación de la florería

### 🛠️ Administrador
- Gestión de clientes
- Gestión de productos
- Consulta de pedidos
- Cambio de estado de pedidos
- Gestión de arreglos personalizados
- Aceptación o rechazo de solicitudes
- Consulta de motivos de no entrega
- Reintento de entregas no realizadas

### 🚚 Repartidor
- Consulta de pedidos listos para entregar
- Inicio de entrega
- Cambio de estado del pedido
- Confirmación de pedidos entregados
- Registro de pedidos no entregados
- Registro del motivo de no entrega
- Perfil del repartidor
